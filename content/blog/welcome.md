This file is a template. Copy it, rename the copy to the URL you want
(`my-new-post.md` becomes `/blog/my-new-post`), and replace everything below
the second `---` line. Change `draft: true` to `draft: false` when the post is
ready to go live.

## Use two hashes for a section heading

The post title above is the page's only top-level heading, so start your
sections with `##` and use `###` for a sub-section inside one.

### A sub-section

Write paragraphs as plain text with a blank line between them. You can make
words **bold** or *italic*, and add a [link to another page](/how-it-works).

- A list item starts with a hyphen
- So does the next one

1. A numbered list starts with a number
2. And carries on

> A line that starts with `>` becomes a pull quote.

## Adding an image

Put the file in `public/blog/` and write
`![A sentence describing the picture](/blog/file-name.jpg)`. The description
is required — the site will refuse to build without it.
